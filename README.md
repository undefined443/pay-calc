# PayCalc

薪资税后计算器，面向中国大陆居民个人：输入税前薪资和年终奖，展开从税前收入到现金到手的完整计算过程，对比年终奖单独计税与并入综合所得哪个更划算，并估算北京、上海、深圳、广州、杭州的五险一金支出。使用 React、TypeScript 和 Vite 构建，计算在浏览器本地完成。

## 功能

- 按税前月薪与发薪月数，或不含年终奖的年度收入填写薪资，年终奖单独填写并计入年度总收入。
- 展示应纳税所得额、适用税率、速算扣除数、全年个税、税后年收入、月均到手及有效税率。
- 对比全年一次性奖金单独计税与并入综合所得的结果。
- 切换北京、上海、深圳、广州、杭州的个人五险一金估算，或手填实际年度缴费。
- 调整社保及公积金参考工资、公积金比例、上海补充公积金与深圳医保档次。
- 手填专项附加扣除合计，或按住房租金月数与其他项目分项填写。

城市模式采用 2026-10-20 规则快照，按当前单月缴费标准乘以 12 年化估算，未按年中调基分段。部分参数仍待复核，详见[五城政策资料](docs/city-policies.md)。精确核算全年个税时，请使用实际年度缴费。

## 快速开始

需要 Node.js 24.19+ 和 npm 12。

```bash
git clone https://github.com/undefined443/pay-calc.git
cd pay-calc
npm ci
npm run dev
```

打开终端显示的本地地址，通常为 `http://localhost:5173/`。端口被占用时，Vite 会选择其他端口。按 `Ctrl+C` 停止开发服务。
